### Connecting Python with Mysql

1. Your pip and python should be installed(this is for IDLE)
2. Your MySQL should also be installed along with Server, Workbench and Shell
3. .And both Python and MySQL have it's PATH in the system variables
4. Open CMD (If normal mode doesn't execute please run CMD as administrator)
5. Type "pip install mysql-connector-python" and press enter and it will take time and then it's show installed successfully.

&emsp;**imp:- good internet connection**



### To get the Database in my Local MySQL

1. Download the sql text file and save it.
2. Open your MySQL Command Line and create a new Database with name you like.
3. Get your MySQL bin file path it be either in any drive that has your program files then either in Program files(x86) or Program File then MySQL File then MySQL server then you'll see bin file right click and click copy as path.
4. Then open where you had save the sql text file and right click and save as path.
5. Open CMD then type "cd and the MySQL bin path you copied"
6. After the Directory is changed to the MySQL Bin Type "MySQL -u root/YOUR\_MYSQL\_USERNAME -p the new database name< path of the sql text file" click enter. it'll ask your MySQL password and it will take time but after it show the directory path again it is done.

&emsp;**imp:- if this doesn't work run cmd as admin**
